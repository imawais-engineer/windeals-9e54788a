# WIN DEALS MVP v0.1

## Build
- Create the light, revenue-focused WIN DEALS visual system with Inter typography, semantic brand and deal-health colors, responsive navigation, and reusable buttons, badges, cards, tables, and modal patterns.
- Add a robust shared mock dataset of 25 B2B deals with values, stages, scores, signals, risks, stakeholders, activity histories, diagnoses, and recommended actions.
- Build the public landing, login, signup, onboarding, and HubSpot mock connection experiences.
- Build the authenticated shell and Dashboard, Deals, Deal Detail, Insights, and Settings screens with all requested metrics, filters, interactions, and navigation.
- Add route-specific page titles and social metadata for every screen.

## Interactions
- Search and filter the deals table, open any deal, draft/copy/edit an email, create a mock task, refresh/sync data, manage notification settings, and complete the onboarding/CRM connection flow.
- Keep CRM behavior mocked for this frontend MVP; no live HubSpot data or persistent account system will be added.

## Validation
- Verify the app builds without errors.
- Exercise the primary flow in the browser from landing to dashboard, deals, deal detail, and email drafting at desktop and mobile widths.
